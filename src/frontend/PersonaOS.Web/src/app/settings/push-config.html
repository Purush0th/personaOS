PersonaOS uses your own Firebase project, so no key is shared with anyone. Both files come from the Firebase console:

  1. Service account key — Project settings → Service accounts → Generate new private key.
  2. google-services.json — Project settings → General → add an Android app with package name com.personaos.personaos_mobile, then download the file.

The key is encrypted on the server and never shown again — uploading replaces it.
